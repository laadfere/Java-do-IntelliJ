# API RESTful com Autenticação e Segurança JWT em Spring Boot

Este repositório contém uma aplicação back-end desenvolvida em Java utilizando a biblioteca Spring Boot, focada em práticas de segurança da informação e autenticação.

## 🛠️ Tecnologias Utilizadas
- Java
- Spring Boot
- Spring Security
- JSON Web Token (JWT)

## 📌 Funcionalidades
- Autenticação de usuários via tokens JWT.
- Controle de acesso e autorização por rotas de endpoint.
- Criptografia e tratamento seguro de dados.
